## 🚀 Projetos em Destaque

* **[To-Do List - API & React](https://github.com/pedromarq40/To-Do-List)** ![Python](https://img.shields.io/badge/python-3670A0?style=flat&logo=python&logoColor=ffdd54) ![Django](https://img.shields.io/badge/django-%23092E20.svg?style=flat&logo=django&logoColor=white) ![React](https://img.shields.io/badge/react-%2320232a.svg?style=flat&logo=react&logoColor=%2361DAFB): Projeto desenvolvido para aprender e consolidar os fundamentos do Django REST Framework. Consiste numa aplicação de lista de tarefas (*To-Do List*) que utiliza os *models* do Django para a estruturação da base de dados, implementação de autenticação JWT para segurança e integração completa com uma interface construída em React.

* **[Trabalho Final - PWEB I](https://github.com/pedromarq40/Trabalho-PWEB-IFAL)** ![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=flat&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=flat&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/javascript-%23F7DF1E.svg?style=flat&logo=javascript&logoColor=black) ![Git](https://img.shields.io/badge/git-%23F05033.svg?style=flat&logo=git&logoColor=white): Projeto final da disciplina de Programação Web I pelo IFAL. Desenvolvido em trio, o trabalho é uma breve releitura de um sistema académico, contando com um sistema de notas e gestão de utilizadores. A aplicação utiliza a manipulação de objetos e `localStorage` no JavaScript para o armazenamento de dados, além de colocar em prática a experiência colaborativa utilizando versionamento de código com Git e GitHub.
